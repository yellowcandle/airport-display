About the Board
關於此板

A web recreation of the split-flap “AIRCRAFT DEPARTURES / 離港班機” board from Hong Kong’s old Kai Tak Airport, driven by live Hong Kong International Airport data — real flights, gates, and codeshares flipping through today’s schedule as they would have in the 1990s.

這是香港舊啟德機場「離港班機」翻牌顯示板的網頁重現，以香港國際機場的 即時航班資料驅動 — 真實的航班、閘口與聯營班號，如同九十年代一樣，隨着今天的時刻表翻動。

Kai Tak 啟德機場

Kai Tak was Hong Kong’s international airport from 1925 until 6 July 1998, famous for its heart-stopping “checkerboard” approach over Kowloon rooftops to a single runway jutting into the harbour. It closed overnight when operations moved to Chek Lap Kok. This board is a tribute to the departures hall that sent so many off.

啟德機場自一九二五年起擔任香港的國際機場，直至一九九八年七月六日。 它以驚險的「棋盤山」降落聞名 — 飛機低掠九龍屋頂，降落於伸進維港的單一跑道。機場於一夜之間關閉， 運作遷往赤鱲角。此板謹向那個送別無數旅人的離境大堂致敬。

Data & credit 資料來源

Flight data comes from the Hong Kong International Airport flight information API, operated by the Airport Authority Hong Kong and published as open data via data.gov.hk. It is free and requires no key.

航班資料來自香港國際機場的航班資訊系統，由香港機場管理局營運， 並透過 資料一線通 以公開資料形式發布，免費且無需密鑰。

The kaiti (楷書) Chinese type is Free HK Kai (自由香港楷書), an open font by a group of Hong Kong elders.

中文楷書字型為 自由香港楷書， 由一群香港長者發起的開源字體項目。

How it works 技術

A Cloudflare Worker serves the static board and proxies the HKIA API server-side — the upstream returns 403 to any request carrying an Origin header, so a browser cannot call it directly. The Worker trims and edge-caches the payload for 60 seconds. No framework, no build step.

一個 Cloudflare Worker 負責提供靜態頁面，並在伺服器端代理機管局的 API — 上游對任何帶有 Origin 標頭的請求都回應 403，故瀏覽器無法直接呼叫。Worker 精簡資料並於邊緣快取六十秒， 不用框架，亦無建置步驟。
